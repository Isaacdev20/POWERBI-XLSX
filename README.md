
# Indicadores Socioeconômicos

Este repositório contém bases de dados utilizadas na construção de dashboards no Power BI.

## Bases de dados
- PIB e PIB per capita
- População municipal
- Indicadores de pobreza
- IDHM
- Saldo anual de empregos

## Ferramentas utilizadas
- Power BI
- Excel
- CSV
- DAX

## Objetivo
Analisar indicadores socioeconômicos dos municípios por meio de visualizações interativas.
